  Summary of Fixes

  Critical Bug Fixed: LAB to RGB Conversion

  Problem: The original code cast LAB values directly to uint8 before color

  - L channel: 0 to 100
  - a channel: -128 to +127
  - b channel: -128 to +127

  Casting negative values to uint8 causes wraparound (e.g., -50 becomes
  206), completely corrupting the color conversion for both original and
  reconstructed images identically, hiding all visible differences.

  Solution: Properly scale and shift LAB values to OpenCV's expected format
  before casting to uint8:
  # Convert LAB to OpenCV format (L: 0-255, a/b: 0-255 shifted from 
  -128,127)
  lab_cv2 = np.zeros_like(lab_hwc, dtype=np.float32)
  lab_cv2[:, :, 0] = lab_hwc[:, :, 0] * 255.0 / 100.0  # L: 0-100 -> 0-255
